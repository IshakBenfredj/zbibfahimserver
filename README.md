# 🚗 En Panne Backend API (Node.js + Express + MongoDB)

خادم منصة **En Panne** لخدمات السيارات وقطع الغيار (الميكانيكيون، كهربائيو السيارات، وبائعو قطع الغيار).

---

## 📦 التقنيات المستخدمة
- **Node.js + Express.js:** بناء الـ RESTful API.
- **MongoDB + Mongoose:** قاعدة بيانات المستندات مع دعم الفهارس الجغرافية `2dsphere`.
- **JWT (JSON Web Token) & Bcrypt.js:** المصادقة وتشفير كلمات المرور وحماية المسارات.
- **Multer:** رفع وتخزين صور قطع الغيار والورشات والشهادات.
- **GeoJSON & Haversine:** حساب المسافات الجغرافية الدقيقة بالكيلومترات بين الزبون وأصحاب المحلات والورشات.

---

## 🚀 تشغيل السيرفر

### 1. تثبيت الحزم (Dependencies):
```bash
cd server
npm install
```

### 2. إعداد ملف البيئة (`.env`):
يحتوي مجلد `server/` على ملف `.env` جاهز. تأكد من تشغيل MongoDB محلياً أو وضع رابط Atlas في متغير `MONGODB_URI`:
```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://localhost:27017/en_panne_db
JWT_SECRET=en_panne_super_secret_jwt_key_2026_auto_mechanic
JWT_EXPIRE=30d
BASE_URL=http://localhost:5000
```

### 3. زرع بيانات تجريبية (Seeder):
لتعبئة قاعدة البيانات بورشات ميكانيك وكهرباء ومحلات قطع غيار تجريبية حول العاصمة:
```bash
node src/utils/seeder.js
```

### 4. بدء تشغيل الخادم:
```bash
npm start
# أو للتطوير مع التحديث التلقائي:
npm run dev
```

## 📡 خريطة الـ Endpoints (API Routes)

### 1. المصادقة وإدارة الحساب (`/api/auth`)
| المسار | الطريقة | الوصف | الصلاحية |
| :--- | :---: | :--- | :--- |
| `/api/auth/register` | `POST` | إنشاء حساب جديد (زبون، بائع، ميكانيكي، كهربائي) | عام |
| `/api/auth/login` | `POST` | تسجيل الدخول برقم الهاتف وكلمة المرور | عام |
| `/api/auth/me` | `GET` | استرجاع بيانات المستخدم المسجل حالياً | مصادقة |
| `/api/auth/profile` | `PUT` | تعديل الملف الشخصي والخدمات وساعات العمل | مصادقة |
| `/api/auth/avatar` | `POST` | رفع صورة الحساب الشخصي أو شعار المحل | مصادقة |

### 2. مقدمو الخدمات والمحلات (`/api/providers`)
| المسار | الطريقة | الوصف | الصلاحية |
| :--- | :---: | :--- | :--- |
| `/api/providers/nearby` | `GET` | جلب الورش والمحلات القريبة بحساب المسافة الدقيقة بالكيلومتر عبر `$geoNear` | عام |
| `/api/providers/:id` | `GET` | عرض تفاصيل مقدم الخدمة وقائمة الخدمات والأسعار التقديرية بدينار جزائري | عام |

### 3. طلبات البحث عن قطع الغيار (`/api/requests`)
| المسار | الطريقة | الوصف | الصلاحية |
| :--- | :---: | :--- | :--- |
| `/api/requests` | `POST` | نشر طلب قطعة غيار جديد مع الصور والموقع الجغرافي | زبون فقط |
| `/api/requests/my` | `GET` | قائمة طلباتي التي قمت بنشرها مع عدد العروض الواردة | زبون فقط |
| `/api/requests/nearby` | `GET` | استعراض الطلبات القريبة للمحلات مع حساب المسافة للزبون بالكيلومتر | بائع فقط |
| `/api/requests/:id` | `GET` | تفاصيل طلب قطعة غيار محدد | مصادقة |
| `/api/requests/:id/status`| `PATCH` | إغلاق الطلب بعد الشراء أو إلغاؤه | صاحب الطلب |

### 4. عروض الأسعار والردود (`/api/quotes`)
> **🔒 ميزة الخصوصية (Privacy & Confidentiality):**
> السعر المقترح من طرف صاحب المحل يظهر للزبون صاحب الطلب فقط، وتُحجب الأسعار تلقائياً عن المحلات المنافسة والمستخدمين الآخرين.

| المسار | الطريقة | الوصف | الصلاحية |
| :--- | :---: | :--- | :--- |
| `/api/quotes` | `POST` | تقديم عرض سعر وملاحظات وتوفر التوصيل على طلب محدد | بائع فقط |
| `/api/quotes/request/:requestId` | `GET` | استعراض عروض الطلب (مع حجب أسعار المنافسين للغير) | مصادقة |
| `/api/quotes/my-offers` | `GET` | استعراض العروض التي قدمها البائع الحالي | بائع فقط |

### 5. التقييمات والآراء (`/api/reviews`)
| المسار | الطريقة | الوصف | الصلاحية |
| :--- | :---: | :--- | :--- |
| `/api/reviews` | `POST` | تقييم مقدم خدمة أو محل بالنجوم (1-5) والتعليق | زبون فقط |
| `/api/reviews/provider/:id` | `GET` | عرض تقييمات وآراء العملاء لمقدم الخدمة | عام |

## ⚡ أحداث الوقت الفعلي (Socket.io Real-time Events)

يدعم الخادم الاتصال اللحظي الحي عبر **Socket.io** لتبادل العروض والطلبات فورياً:

### 1. غرف الاتصال (Rooms):
- `join_user(userId)`: ينضم المستخدم لغرفته الخاصة لاستقبال العروض الموجهة له حصراً.
- `join_sellers`: تنضم محلات قطع الغيار لتلقي إشعارات الطلبات الجديدة المنشورة.
- `watch_request(requestId)`: لمراقبة عروض طلب محدد في الوقت الفعلي.

### 2. الأحداث المنبعثة (Emitted Events):
| الحدث | المستلم | المحتوى |
| :--- | :--- | :--- |
| `new_part_request` | غرفة البائعين `sellers` | إشعار فوري بطلب جديد (السيارة، القطعة، الموقع). |
| `new_quote_received` | الزبون صاحب الطلب `user:<clientId>` | إشعار فوري بالعرض مع السعر المقترح والمسافة اللحظية بالكيلومتر `distanceKm`. |
| `quote_count_updated` | مراقبو الطلب `request:<id>` | تحديث عدد العروض الواردة على الطلب فورياً. |

## 📍 الحساب الديناميكي للمسافة (Dynamic Distance On-The-Fly)
- **لا يتم تخزين المسافة في قاعدة البيانات** كقيمة ثابتة، بل تُحسب ديناميكياً في الوقت الفعلي بناءً على موقع الزبون الحالي لحظة استدعاء الـ API أو إحداثيات تعطل السيارة مقابل إحداثيات المحل.
